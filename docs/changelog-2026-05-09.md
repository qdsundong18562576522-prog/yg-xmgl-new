# 2026-05-09 开发日志 — 采购链条模块完成

> 本次开发完成了采购链条全部模块：材料设备库 → 采购申请 → 采购询价 → 采购确认 → 供货通知，并对项目管理模块进行了完善。

---

## 一、新增功能

### 1. 材料设备库
- 材料库 CRUD（搜索、新增、编辑、删除）
- MaterialSearch 组件（采购表单中联动选择材料）
- 仅采购和管理员可操作

### 2. 采购申请
- 新建/编辑/提交/审批/撤回/删除
- 采购明细表格（材料名称、品牌、规格、单位、数量、合同单价）
- **导入/导出/下载模板**（Excel 格式，支持 .xlsx/.xls/.csv）
- 到货地址、收货人（手动输入）、电话、要求到货时间、备注
- 审批流：提交 → 领导/管理员审批通过/驳回

### 3. 采购询价
- 基于已审批采购申请创建，自动引出采购明细（只读）
- 采购单价手动输入，自动计算合价和小计
- 额外费用（名称+金额，可正可负，非必填）
- 底部自动统计：材料小计 + 额外费用小计 = 采购总价
- 两级审批：PM审批 → 领导审批

### 4. 采购确认
- 基于已审批询价单创建，自动复制明细
- 合同附件上传（支持 .pdf/.jpg/.png/.doc 文件上传）
- 发货及付款条件、供货周期
- 两级审批：PM审批 → 领导审批

### 5. 供货通知单
- 基于已审批采购确认创建，自动复制明细
- 运输方式（下拉：陆运/空运/送货上门/自提）
- 陆运/空运时弹出"单号"输入框（必填）
- 最晚到货日期、到货方式（一次性/分批次）
- 已使用的采购确认自动从下拉列表过滤

### 6. 项目管理完善
- **查看详情弹窗** — 展示项目全部字段
- **参与人员** — 多选，相关人员可在项目列表看到该项目
- **销售负责人多选** — 可选多个销售
- Admin可编辑任何状态的项目
- 删除时检查是否有关联采购申请

### 7. 用户管理完善
- 编辑用户（姓名、角色、部门、电话）
- 启用/停用用户
- 删除用户（admin 账号不可删除）
- 页面仅 admin 可见

## 二、系统级功能

### 自动编号
| 表单 | 格式 |
|------|------|
| 项目 | `YGKI-{类型}-{日期}-{流水号}` |
| 采购申请 | `CGSQ-{日期}-{流水号}` |
| 采购询价 | `CGCX-{日期}-{流水号}` |
| 采购确认 | `CGQR-{日期}-{流水号}` |
| 供货通知 | `GHTZ-{日期}-{流水号}` |

### 唯一引用链（级联保护）
```
项目 → 采购申请 → 采购询价 → 采购确认 → 供货通知
```
每级引用唯一，有下级关联时禁止删除。

### 审批记录
- 所有审批操作写入 `approval_history` 表
- 查看弹窗显示审批记录时间线（操作人、操作、时间、备注）
- 审批历史查询接口：`GET /approval-history?entityType={type}&entityId={id}`

### 撤回功能
- 审批中的单据可由发起人或 admin 撤回至草稿
- 撤回后可重新编辑、提交或删除

### 文件上传
- 合同附件上传至 `backend/uploads/` 目录
- 通过 `/uploads/{文件名}` 访问
- 上传接口：`POST /api/v1/upload`

### 权限
- admin — 全部权限（审批、编辑、删除）
- leader — 领导审批
- pm — 项目经理操作+审批
- purchaser — 采购操作+审批
- sales — 销售操作
- engineer — 工程人员（查看+部分操作）
- 侧边栏菜单根据角色动态过滤（用户管理、系统设置仅 admin 可见）
