# 扬光工程管理系统

面向工程类企业的项目全过程管理平台，覆盖从项目立项、采购、库存、劳务、费用到回款的全链条业务。

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | NestJS + TypeScript |
| 数据库 | PostgreSQL + Prisma ORM |
| 前端框架 | React 19 + TypeScript + Vite 8 |
| UI 组件库 | Ant Design 6.x |
| 状态管理 | Zustand + TanStack React Query |
| 认证方式 | JWT（独立认证）|

## 端口

| 服务 | 端口 |
|------|------|
| 后端 API + 前端静态文件 | 12404 |

## 模块列表

### 项目管理
- **项目立项** — 项目创建/编辑/审批/查看，销售负责人多选，参与人员
- **工程量变更** — 基于项目的手动变更，工程量可正可负，审批后更新台账

### 采购管理
- **材料设备库** — 全局材料管理，模糊搜索，批量删除
- **采购申请** — 采购明细录入，导入/导出 Excel，逐级审批
- **采购询价** — 按供应商分组提报，采购单价录入，额外费用（可正可负），两级审批
- **采购确认** — 按供应商分组合同，合同附件上传，两级审批
- **供货通知** — 按合同提报，运输方式（陆运/空运/送货上门/自提），运单号跟踪

### 库存管理
- **公司库存** — 全局库存管理，采购单价记录
- **项目库存** — 按项目查看，支持出库（已安装）和转入公司库存
- **转库记录** — 一键转公司库存审批流程（领导→采购）
- **材料领用** — 从公司库存领用至项目，自动带出采购单价，支持自提/快递物流

### 项目费用管理
- **费用申请** — 项目费用申请，领导审批 → 财务打款
- **费用报销** — 发票上传（多文件），角色区分审批流程
- **工程量变更** — 移至项目管理模块

### 劳务管理（占位）
- **劳务合同确认** — 功能开发中
- **劳务签证** — 功能开发中

### 系统管理
- **用户管理** — 账号创建/编辑/启用/停用/删除

## 快速开始

```bash
# 克隆项目
git clone https://github.com/qdsundong18562576522-prog/yg-xmgl-new.git
cd yg-xmgl-new

# 后端
cd backend
npm install
# 配置 .env 中的 DATABASE_URL
npx prisma db push
npx tsx prisma/seed.ts  # 创建默认管理员 admin / admin123
npm run build
node dist/src/main.js    # 访问 http://localhost:12404

# 前端（开发模式）
cd ../frontend
npm install
npm run dev              # 访问 http://localhost:12403
```

## 核心功能

### 自动编号
所有表单自动生成唯一编号，格式：`{前缀}-{YYYYMMDD}-{流水号}`。

| 表单 | 编号前缀 |
|------|---------|
| 项目 | YGKI |
| 采购申请 | CGSQ |
| 采购询价 | CGCX |
| 采购确认 | CGQR |
| 供货通知 | GHTZ |

### 审批流
每个流程都有完整的审批状态流转：`草稿 → 审批中 → 已通过 / 已驳回`。
审批中的单据可撤回重新编辑。所有审批操作记录审批历史，可在查看弹窗中追溯。

### 库存流转
```
供货通知审批 → 自动入库项目库存（带采购单价）
  ├── 出库（已安装）→ 移出项目库存
  └── 转入公司库存 → 审批（领导→采购）→ 入公司库存（成本仍记原项目）
                        ↓ 其他项目材料领用
                        → 成本从原项目转移到领用项目
```

### 级联保护
表单之间逐级关联，有下级引用时禁止删除父级数据。
